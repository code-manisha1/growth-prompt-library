# 📚 Growth Prompt Library

A growing collection of tested AI prompts for everyday **growth and marketing work**: creator outreach, campaign briefs, performance summaries and more.

>  **Work in progress.** I'm adding prompts as I test them in my own work.

---

## The Problem

In growth roles, I write similar things again and again: outreach messages to creators, campaign briefs, follow-ups and performance summaries. I was rewriting AI prompts from scratch every time, and the results were inconsistent.

##  What I Built

A simple, organised library of prompts. Each one has:

- **When to use it:** the situation it's for
- **The prompt:** ready to copy, with `[placeholders]` to fill in
- **Example input and output:** using made-up sample data
- **Tips:** what I changed to get better results
